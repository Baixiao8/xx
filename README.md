# 技术产品 AI 英文术语知识卡

这是一个面向产品、设计、研发和 AI 协作场景的英文术语知识库。目标不是做传统单词本，而是帮助团队理解技术词汇在真实工作沟通中的语义、边界和常见表达。

## 内容

- `docs/terms.md`：完整知识卡文档，适合直接阅读。
- `data/terms.json`：结构化词库，适合做网页、搜索、导入工具或二次开发。
- `assets/images/`：中文语义插画资源。
- `scripts/build_terms_json.mjs`：从 `docs/terms.md` 重新生成 `data/terms.json` 的脚本。

## 卡片字段

每个术语尽量包含：

- 分类
- 词汇
- 标准发音
- 中文谐音
- 拆词/来源
- 一句话理解
- 中文工作表达
- 画面联想
- 故事记忆
- 实际应用场景
- 不要误解为
- 常见表达
- 真实沟通例句
- 图片生成提示词

部分重点术语已配中文语义插画，帮助建立直观记忆。

## 当前规模

- 术语卡片：87 个
- 中文语义插画：87 张

已覆盖方向：

- 产品与增长
- 设计与前端表达
- 开发协作与工程流程
- 后端与基础设施
- AI 基础概念
- AI 进阶与前沿术语

## 重新生成 JSON

修改 `docs/terms.md` 后，可以运行：

```bash
node scripts/build_terms_json.mjs
```

脚本会根据 Markdown 中的编号标题和字段内容生成 `data/terms.json`。

## 使用建议

- 给团队阅读：直接使用 `docs/terms.md`。
- 做内部网页或搜索工具：使用 `data/terms.json` 和 `assets/images/`。
- 持续扩展词库：优先编辑 `docs/terms.md`，再运行脚本同步 JSON。
